# M7 — Teacher licence & trust: acceptance

The exit gate (MILESTONES §6, M7): tests green · **the teacher requests a licence and runs an exam with it**.

The tests are green, and the gate's journey runs end to end in the built app (`tests/e2e/licence.spec.ts`) — with
a **test's own author key**. The real one doesn't exist yet: **the author's key has to be made by the author**,
with a passphrase only the author knows (§4, step 1). Until then no installed ExamMode can be a teacher's, and
none lists any exam.

MicroLab has this designed (its Rev 16, M13) but not built: there was no `npm run licence` or author key to
reuse. ExamMode's is the first; MicroLab can take the same tool and the same key later.

## 3. What is signed, and what isn't

| | |
|---|---|
| The announcement of an exam, and the list a typed-in computer name gets | signed; the licence travels in it |
| Every message from the teacher's laptop to a student | signed for that connection (the student's own random word) and counted: not another laptop's, not played again, not played to another student |
| The answer to a backup or a hand-in | signed over the student's token and exactly the files sent |
| The files the teacher gives | checked against their SHA-256, which came in a signed message |
| **The class list** (the names to pick from) | **not signed**. A laptop in between could show other names; joining still needs the pinned teacher's signed answer |
| What a student's ExamMode sends | not signed, as before (R7: the teacher's laptop is the authority, the teacher is in the room) |
| The exam a lab computer remembers for coming back after a sudden stop | the teacher's key is remembered with it, in a file a student could edit — R7 again |

## 4. For the teacher (the author)

**To do, in this order — the gate isn't passed until step 4:**

1. `npm run licence -- init` on your own computer. It asks for a passphrase (12 characters or more) and makes
   your key in `~/.codingspacekh/`. Keep a copy of that folder somewhere safe. It writes the key's public half into
   `src/lib/trust/author.json`: commit that file.
2. Say which address a teacher's request should go to (`requestAddress` in the same file). It is empty: the screen
   says *send this text to CodingSpaceKH*, with no address and no email button. MicroLab's design names your Gmail
   address; I didn't put it into this public repository without your word.
3. On your Mac: ExamMode → *I'm a teacher…* → fill it in → copy the request into a file → `npm run licence -- request.txt` → *I have a licence file…* → *Start again in teacher mode*.
4. Run an exam with it.

**Things I decided. Each needs your yes or no:**

| # | Case | What I made it do | Why |
|---|---|---|---|
| 1 | **No teacher passcode** | The teacher's key is sealed by the Mac's keychain (Windows: its own), not by a passcode typed for every exam | MicroLab's passcode is for a computer students share; ExamMode's teacher mode is on the teacher's own laptop, and a passcode before every exam is one more thing to forget |
| 2 | **The request is sent by email, as text** | No form on codingspacekh.dev; *Copy*, and *Open in my email app* once the address is set | MicroLab's fallback screen (36b); there is no form to send to yet |
| 3 | **Where *I'm a teacher…* is** | A quiet link under the Join card | A lab computer's ExamMode has no menu bar; the prototype has no such screen |
| 4 | **Teacher mode is the licence** | With a licence for its key ExamMode starts in teacher mode, with no question; `--student` starts it as a lab computer's | One app (D1) |
| 5 | **A development build** | Takes a teacher with no licence, and can be one (`--teacher`); Make an exam says so. An installed ExamMode never does | The plan: *unsigned mode removed from release builds* |
| 6 | **A licence taken back** | Its number goes into `withdrawn` in `author.json`: every ExamMode built after that refuses it | No server to ask; an update carries the list |
| 7 | **A new computer** | A new request and a new licence; the tool says a licence was given to that address before | The key never leaves the computer it was made on |
| 8 | **The licence's file** | `.emlicence`, JSON; ExamMode's own (`app: exammode`) — a MicroLab licence isn't taken | Each app asks for its own |
