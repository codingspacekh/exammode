## 2. The Windows spike on GitHub (step 5, short run)

`node spikes/windows/run-all.mjs` on GitHub's **Windows Server 2022** (Windows 10's code base, 10.0.20348) and
**Windows Server 2025** (Windows 11's, 10.0.26100), as administrator. 1024 × 768 screen, 16 GB, virtual machines.

| Probe | Server 2022 | Server 2025 | Target |
|---|---|---|---|
| **Keyboard hook** in a koffi worker (60 s, ≈ 1 000 key presses): Windows key, Ctrl+Esc, Alt+Esc swallowed; the next hook never sees them; both hooks alive at the end | ✅ slowest call 1.2 ms | ✅ slowest call 1.4 ms | Windows drops a hook at ≈ 1 000 ms |
| **A new window** (Notepad) seen by the window-event hook and its program closed — worst of 5 | ✅ 11 ms | ✅ 44 ms | N-02: < 1 000 ms (aim 500) |
| One `EnumWindows` sweep with every program's path (the 500 ms backstop) | 0.9 ms | 1.0 ms | — |
| **The exam bar as an AppBar**: work area starts under it (54 px); Notepad maximised fits under it; work area back to normal after | ✅ top 54; Notepad top 46 (= 54 − its 8 px border) | ✅ same | D6 |
| **DisableTaskMgr** takes effect at once (no sign-out) and is put back | ✅ | ✅ | §2.4 |
| **Explorer**: killed, stays down with `AutoRestartShell=0`, started again; the setting put back | ✅ back in 114 ms | ✅ back in 214 ms | D7 |
| **Firewall**: outbound blocked except one program — curl blocked, the allowed program reaches the internet; all put back | ✅ applied 2.4 s, restored 2.9 s | ✅ applied 3.4 s, restored 4.9 s | D8, F-23 |
| **Electron fuses**: with RunAsNode off, `ELECTRON_RUN_AS_NODE=1 electron -e …` runs nothing (without the fuse it runs) | ✅ | ✅ | D10 |
| **Virtual machine check**: GitHub's runners are recognised as virtual machines | ✅ | ✅ | F-04 |

**Findings for the design**
1. **R1 holds**: koffi hooks in a worker thread with their own message loop are fast and stay installed. No native
   helper is needed. *(To be confirmed by the 30-minute lab run, §3.)*
2. On Windows Server, a killed Explorer did **not** come back by itself even with `AutoRestartShell=1`. Windows 10/11
   desktops are known to restart it, so the lockdown plan keeps setting `AutoRestartShell=0` (journaled). The lab run
   records what a lab computer does.
3. **DNS** worked with outbound blocked and no DNS rule of ours: Windows' own *Core Networking — DNS (UDP-Out)* rule
   allows it. The plan keeps its own DNS rule in case a school has turned the built-in rules off.
4. Applying or restoring the firewall takes **2–5 s** through PowerShell. That's within N-10's 3 s budget only for
   applying on the faster runner; M4 measures it on the i5 and may move to `netsh` or the firewall's COM API.
