# M5 — The exam's apps: acceptance

The exit gate (MILESTONES §6, M5): **the app matrix on a lab computer** — for each profile, the app opens in the
Exam folder, saves there, and each of its known ways out is tried and stopped (Office: Copilot, online pictures,
Open from cloud, a hyperlink; VS Code: Copilot, an extension install, `start chrome` in the terminal; MicroLab:
PyPI install); Office still opens with the internet blocked (R9).

M5 was built without a lab computer, like M4. GitHub's Windows computers have **none of the ten apps** (their own
report, §2: *profiles: none*). So what is proven on real Windows is the way an exam's app is allowed, opened,
brought to the front, kept while other apps are closed, and closed with the exam — with Windows' own Character
Map standing in as an app without a profile. **No profile has yet met its app.** The whole matrix in §4 is open.

## 3. What the tests found, and what changed

| # | Finding | What was done |
|---|---|---|
| 1 | **A program started by ExamMode doesn't get the front by itself**: Windows gives the front only to what the window in front started by a click | After an app is opened from the bar, each look at the processes (twice a second) brings its window to the front until it is there, for 5 seconds at most. Trying once wasn't enough: one run in four on Server 2022, Windows refused the first try |
| 2 | **An app that is open in the Exam folder keeps Windows from removing the folder** — the hand-in never ended: no *Handed in*, the computer locked for good | Once the teacher has the work the exam's apps are closed, then the folder is removed; a folder that still can't be removed doesn't hold up *Handed in*, and is tried again at Finish |
| 3 | **A lock test that fails can lose GitHub's computer** (no network for its agent → no log) | The test's cleanup undoes a journal that is still there with a new Guard; the workflow lets the firewall out again after 6 minutes whatever happens; the lock test runs only where `EXAMMODE_LOCK_TEST=1` says so |
| 4 | Windows' list of installed programs has browsers in it | Browsers, remote tools, AI apps and recorders are never offered in Add an app (a teacher can still type any program's place) |
