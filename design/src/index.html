{{include:logo}} ExamMode — UI prototype

Static screens for review before any code is written. Each one fills the browser window like the app on a lab computer's 1920 × 1080 screen; resize the window to see the layout follow (check 1280–1920 wide). Requirement IDs (F-12, Q4…) are those the requirements will use. The apps inside the exam (Word, VS Code) are drawn plainly, only to show where they sit under the exam bar.

The idea in one line: on the lab computers, ExamMode keeps a student inside the exam's apps and websites until they hand in; leaving locks them out, and only the teacher can let them back in. The teacher runs the exam from their own computer over the classroom network, live.

Defaults used in this design (to confirm)

  • Q1 / Q12 Windows lab computers, open use: one shared account, no sign-in (10 and 11, 64-bit, 1920 × 1080), set up once by the teacher or IT with an administrator account. Every student has a school email, which a class list can carry (agreed).
  • Q13 Almost nothing to set up (agreed) — no configuration files: an exam is made in screen 11 in a few minutes.
  • Q2 The allowed apps are chosen for each exam, nothing built in (agreed). Exam profiles to start with: Word, Excel, PowerPoint, Access, Project, VS Code, Python IDLE, Thonny, OneEditor and MicroLab; any other app can be added and is only allowed to run.
  • Q3 / Q14 The questions are usually on paper (agreed) — then there is no exam browser and no internet. If the teacher chooses On a website, the exam browser opens only the sites given (the example exam on these screens uses one).
  • Q4 The teacher's computer runs the exam over the classroom network — no account, no internet service needed. Hosting it online could come later.
  • Q5 Closing ExamMode suddenly counts as leaving (a crash looks the same); the teacher can let a student back in.
  • Q6 A lost network is not leaving — the computer stays locked and the student keeps working.
  • Q7 Hand-ins go to the teacher's computer, one folder per student; sending them on to the hand-in site could come later.
  • Q8 Teacher mode is protected so a student's copy can't run an exam (as in MicroLab's teacher licence).
  • Q9 No webcam or screen recording — the teacher in the room does that part.
  • Q10 MicroLab's own exam mode (its .mlexam files) inside ExamMode: MicroLab opens normally under the exam bar, and its own full-screen exam mode isn't needed in an ExamMode exam.
  • Q11 The look is built with shadcn/ui (new-york style, Tailwind v4, Phosphor icons), themed with these screens' tokens, as the gradebook is (agreed) — React in Electron.
